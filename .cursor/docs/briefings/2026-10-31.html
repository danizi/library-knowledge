反编译与逆向的开源项目

这一节不是今日热门榜。你要的 REA 是 morluto/rea，全称 Reverse Engineer Anything。命令行那套是 radare2，AI 插件叫 r2ai。Ghidra 是另一套底座。只从官方仓库安装，同名拷贝不算。

morluto/rea REA

https://github.com/morluto/rea

413,680 星 · 103,481 forks

Reverse Engineer Anything。一个 MCP，让 Agent 在没有源码时查看原生二进制、JavaScript / Electron、.NET 和网站，并给出证据。分析在本机跑。原生分析可接已安装的 Hopper、Ghidra、IDA 或 Kuna。

用法
  1. 只从 morluto/rea、rea.tools 或 npm 包 rea-agents 安装。同名仓库不算官方。
  2. 已装 Node.js 时运行 npx rea-agents setup，在列表里选 Cursor，同意改动后重启 Agent。
  3. 然后直接说要查的应用和功能，例如「说明 Notes 的搜索怎么实现，并给出证据」。

NationalSecurityAgency/ghidra 反编译器，不是模型

https://github.com/NationalSecurityAgency/ghidra

96,314 星 · 10,864 forks

NSA 的开源逆向框架。能反汇编、反编译、画调用图，并用 Java 或 Python 写脚本。后面几个 AI 项目都站在它或同类工具上。

用法
  1. 从 GitHub Releases 下载发行包并解压。
  2. 运行 ghidraRun，导入二进制，打开 Decompile 窗口。
  3. 要给 AI 用，再装下面的 MCP 插件，而不是把整个安装目录交给模型。

radareorg/radare2 常被叫成 rae / r2

https://github.com/radareorg/radare2

25,216 星 · 3,395 forks

开源的命令行逆向框架。能反汇编、调试、改二进制。它自己的反编译插件有 r2dec（pdd）和 r2ghidra（pdg）。用大模型反编译要再装 r2ai 里的 decai。

用法
  1. macOS 可 brew install radare2，或按仓库用 meson 编译。
  2. 用 r2 文件 打开，aaa 做分析，pdf 看反汇编。
  3. 装 AI：r2pm -Uci r2ai，反编译用 r2pm -Uci decai。

radareorg/r2ai decai

https://github.com/radareorg/r2ai

490 星 · 59 forks

radare2 的 LLM 插件。r2ai 负责提问、自动执行 r2 命令；decai 专门做增强反编译，例如给变量起名、解释当前函数、把伪代码改得可读。

用法
  1. 先装好 radare2，再执行 r2pm -Uci r2ai 和 r2pm -Uci decai。
  2. 在 r2 里运行 r2ai -q，选 decompile。
  3. 模型可接本机 ollama，或 OpenAI、Anthropic 等。输出要回 r2 里核对，不能当还原出的源码。

mrexodia/ida-pro-mcp 插件开源

https://github.com/mrexodia/ida-pro-mcp

13,231 星 · 1,605 forks

把 IDA Pro 接上语言模型的 MCP 服务：模型可以驱动反编译器查函数、改名、看交叉引用。IDA 本体是商业软件，这个仓库只是桥。

用法
  1. 先有可用的 IDA Pro。
  2. 按仓库 README 安装插件，并在 Cursor 里添加这个 MCP。
  3. 让模型只读反编译结果，重命名和写注释再人工确认。

LaurieWired/GhidraMCP

https://github.com/LaurieWired/GhidraMCP

11,670 星 · 1,247 forks

Ghidra 的 MCP 服务。模型可以反编译、列出函数和导入导出，并提议重命名。也可以不打开 Ghidra 界面，用 PyGhidra 做无界面分析。

用法
  1. 把扩展装进 Ghidra，并设置 GHIDRA_INSTALL_DIR。
  2. 无界面示例：uvx --python 3.13 --from "ghidra-mcp[headless] @ git+https://github.com/LaurieWired/GhidraMCP" ghidra-mcp --headless --binary 目标文件
  3. Python 需 3.10–3.13，Ghidra 版本以仓库说明为准。

bethington/ghidra-mcp

https://github.com/bethington/ghidra-mcp

6,023 星 · 368 forks

另一套 Ghidra MCP，工具更多（约 200 项）：反编译、调用图、数据流、结构体恢复，以及 Docker 部署。

用法
  1. 按 README 选择图形界面插件或无界面服务。
  2. 和 LaurieWired 那套不要同时往同一个 Ghidra 实例乱装，先选一个。
  3. 批量改名之前，先让它只导出函数列表给你看。

albertan017/LLM4Decompile

https://github.com/albertan017/LLM4Decompile

7,195 星 · 567 forks

专门把二进制翻成 C 的开源模型系列。End 直接吃二进制；Ref 先让 Ghidra 出伪代码，再把伪代码改得更像人能读的源码。目前主要是 Linux x86_64、GCC O0 到 O3。

用法
  1. 从仓库 Quick Start 或官方 Colab 跑通一个函数。
  2. 要可读性，走 Ref：Ghidra 反编译结果再交给模型。
  3. 混淆过的二进制，作者论文里写明它和 Ghidra 都不可靠，不要当成还原成功。

mahaloz/DAILA

https://github.com/mahaloz/DAILA

711 星 · 60 forks

反编译器里的 AI 插件，不绑死某一个反编译器。可接 GPT、Claude 或本地模型，用来解释和整理反编译结果。

用法
  1. 按 README 装到你已经在用的反编译器里。
  2. 先对一个小函数提问，确认密钥和本地模型地址。
  3. 星标远小于 Ghidra 本体，把它当辅助，不当主反编译器。
