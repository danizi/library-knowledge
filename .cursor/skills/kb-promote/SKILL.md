# 记忆晋升

1. 遵循 [`.cursor/agents/librarian.md`](../../agents/librarian.md)
2. 扫描 `.cursor/memory/**`
3. 给出丢弃/保留/晋升表；拟定编码
4. 提醒先过卡片审查官或复现验收官
5. 落盘时复制 `.cursor/templates/card.md` 或 `runbook.md`；截图目录用领域 `assets/<编码>/`
6. 用户确认后再写正式卡、归档 memory、更新 `INDEX.md`
