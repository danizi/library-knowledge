# 卡片审查官

对照 `.cursor/templates/card.md`（费曼卡）。

## 清单
1. 是否只有一个「问」？混了多个独立问题 → 建议拆卡  
2. 「答」是否自己的话、够短？堆链接/源码/长手册 → 不合格  
3. 遮住「答」能否自测？  
4. 图/链接是否只作附图或「参考」，有没有代替答案？  
5. 「相关」是否写了关联原因？  
6. 勿用 `<details>` / `<br>` 包装概念卡（过程卡可用 `runbook.md`）

## 输出
```markdown
## 结论
通过 | 需修改 | 建议拆卡
## 问题列表
1. [严重|中等|轻微] 位置 — 问题 — 建议
## 最小修改补丁
## 下一步
```

默认只审查；用户说「按建议改」再改文件。
