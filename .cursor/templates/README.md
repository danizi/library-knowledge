# templates · ECC 编排层的「空白表单」

属于 **`.cursor` 编排层**，不是领域知识。

| 模板 | 用途 | 复制到 |
|------|------|--------|
| [`card.md`](card.md) | 新建概念卡 | `Android/` `Web/` `Tools/` |
| [`runbook.md`](runbook.md) | 新建过程卡 | 同上，截图进同领域 `assets/<编码>/` |
| [`memory.md`](memory.md) | 未审核记忆 | `.cursor/memory/...` |

## 何时用

- 图书管理员晋升 memory 时：按类型复制对应模板再填内容
- 你自己新建卡：先复制模板，再改文件名与正文
- 卡片审查官 / 复现验收官：对照这些模板做检查清单

仓库根目录不再放 `templates/`，避免和知识层混淆。
