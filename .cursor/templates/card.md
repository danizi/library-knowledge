# 标题（= 文件名里的标题，一个概念）

<!--
【费曼概念卡 · 写之前看一眼】
费曼四步落在卡上：
  1) 选定概念 → 标题只装一个概念
  2) 用大白话讲清楚 → 「答」（像讲给聪明外行听）
  3) 发现讲不清的地方 → 写进「易错」，回去补资料后再改「答」
  4) 再压缩 → 必须有「一句话」收束；压缩不了就拆成两张卡

硬规则：
  - 「问」只问一件事；能遮住「答」做默念自测
  - 「答」用自己的话；禁止用链接列表 / 大段源码 /「见官方文档」冒充答案
  - 「例 / 类比」优先：一个最小例子，或一个生活类比（费曼最吃这个）
  - 图、长代码、操作步骤 → 附图或过程卡（runbook），别塞进「答」
  - 复制到 knowledge/<领域>/ 后改名：前缀-序号 | 标题.md；写完可删本注释
-->

**问：**
（一句完整问句。复习时只看这里。）

**答：**

一句话：（把上面的「答」压成一句，压不动就拆卡。）

- 类比：… 就像 …
