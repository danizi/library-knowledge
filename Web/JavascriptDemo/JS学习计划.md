# JS 学习计划（12 周，全栈入门，3–5 小时/周）

假设每周 2–3 次、每次 60–90 分钟，设备具备 Node 18+、浏览器和 VSCode。

## 总体策略
- 70% 学习 + 30% 练习；每周至少产出 1 个可运行成果。
- 里程碑：第 6 周前端 Todo 可用；第 9 周完成可调用的 REST API；第 12 周交付可展示全栈项目；每 2 周固定更新 README（运行方式 + 截图/录屏）。
- 复盘：每周写 5 点收获 + 1 个踩坑；每两周做一次小迭代与 demo 检查表（功能/性能/无控制台报错）。

## 周计划与产出
- **第 1 周：语言基础 + 调试习惯**  
  - 内容：类型、作用域、函数、条件/循环、`let/const`；DevTools 断点调试与调用栈查看。每日 20 分钟数组/字符串微练习。  
  - 练习：FizzBuzz、数组求和、字符频次统计；在 DevTools 下断点单步。  
  - 产出：1 页语法速查笔记 + 3 段代码 + 调试截图。
- **第 2 周：数组与对象 + this/原型 + 模块与规范**  
  - 内容：`map/filter/reduce/find`、对象遍历、解构、模板字符串、`this` 绑定、原型链、ESM `import/export`。配置 ESLint + Prettier 基线，新增 `npm run lint`。  
  - 练习：学生成绩统计脚本，包含至少 2 个原型/`this` 场景；跑 lint 并修正。  
  - 产出：带注释的小脚本 + lint 配置文件。
- **第 3 周：异步思维**  
  - 内容：事件循环、宏/微任务顺序表、Promise、`async/await`、错误处理。  
  - 练习：3 道典型 Promise 顺序题；fetch 公共 API 打印 JSON；绘制事件循环笔记图。  
  - 产出：实验代码 + 顺序表 + 图示。
- **第 4 周：DOM 基础与交互**  
  - 内容：DOM 查询/修改、事件委托；防抖/节流（加分）；小组件拆分；可访问性基础（aria-label、键盘操作）。  
  - 练习：点击计数、输入字数、列表高亮；给组件加键盘操作。  
  - 产出：小页面 demo。
- **第 5 周：表单与本地存储**  
  - 内容：表单校验、阻止默认、`localStorage` 序列化/恢复。  
  - 练习：Todo MVP（添加/删除/完成、计数、持久化），补充空状态与快捷键。  
  - 产出：Todo MVP 页面。
- **第 6 周：前端小项目 1.0**  
  - 内容：过滤视图、空状态、loading/错误提示、基础样式。  
  - 练习：打磨 Todo，写 README（安装、用法、截图/录屏）。  
  - 产出：可展示的 Todo 前端 + 第一次 demo 检查表（功能/性能/无报错）。
- **第 7 周：模块化与包管理（Vite）**  
  - 内容：Vite 脚手架、npm scripts 清单（dev/build/test/lint）、环境变量注入。  
  - 练习：拆分 Todo 为多文件模块，完善 `npm run dev/build/lint/test`。  
  - 产出：模块化结构 + 构建命令。
- **第 8 周：Node.js 基础 + 轻量 TS（可选）**  
  - 内容：CommonJS vs ESM、fs/path、dotenv；2 小时 TypeScript（类型推断、接口、泛型函数）。  
  - 练习：Node 脚本批量重命名或读日志；在脚本或 Todo 中加 2–3 处类型注释。  
  - 产出：实用小脚本 + README。
- **第 9 周：REST API**  
  - 内容：Express/Koa 路由、中间件、集中错误处理中间件、日志；`.env` 管理。  
  - 练习：实现 Todo/用户 API（列表/创建/更新/删除），提供 curl 示例。  
  - 产出：可启动的 API 服务。
- **第 10 周：数据库接入**  
  - 内容：SQLite（better-sqlite3）或 MongoDB；数据库初始化/迁移；回滚脚本。  
  - 练习：API 接 DB 完成 CRUD，编写 `init` + `rollback` 双脚本。  
  - 产出：DB 初始化脚本 + 更新后的 API。
- **第 11 周：全栈项目集成**  
  - 内容：前后端联调，错误/空状态、鉴权简版（token 或 mock）。  
  - 练习：记账本/习惯打卡/书签管理任选，接入后端并跑通主要流程。  
  - 产出：联调成功的全栈应用。
- **第 12 周：部署与展示**  
  - 内容：部署到 Render/Netlify/Cloudflare Pages + Serverless；性能与可维护性复查。  
  - 练习：线上环境健康检查、日志查看、异常兜底页面；第 3 次 demo 检查表。  
  - 产出：线上 Demo + 完整 README（安装/运行/部署/改进清单）。

## 测试与验证
- 语言/异步：3–5 个 Jest/Vitest 单测覆盖数组方法与 Promise 链；事件循环题答对率 ≥80%，实验输出符合预期。  
- Todo 前端：手动测试添加/删除/过滤；刷新后状态保持；表单校验提示；快捷键可用；无控制台报错。  
- API：用 `supertest`/`curl` 覆盖 200/400/404/500；集中错误处理中间件能捕获异常；并行 20 次请求验证幂等。  
- 数据库：初始化脚本可重复执行；空库启动成功；`init` + `rollback` 脚本往返后数据一致。  
- 里程碑 demo（第 6/9/12 周）：应用可启动，关键流程走通，网络请求正确返回，无控制台红错。  
- 文档一致性：README 中的安装/运行命令与 package.json 保持一致，脚本命名规范（dev/build/test/lint）。

## 假设与弹性
- 已有 HTML/CSS 基础；样式可用简易方案或 UI 库。  
- Node 18+，npm/yarn 可用；无代理时优先官方源或国内镜像。  
- 时间不足：优先保留异步周、Todo 前端、API + DB、终期部署；可选项（TS/防抖/可访问性）视时间投入。  
- 记录：每周末提交代码与笔记到仓库，便于回顾与对比。

## 精选资源（按周对照阅读）
- MDN：语言指南（周 1–2）、Promise/事件循环（周 3）、DOM/事件（周 4–5）、Fetch/存储（周 5）。
- You Don’t Know JS Yet：Scopes & Closures（周 1–2），Async & Performance（周 3）。
- 官方文档：Vite 入门（周 7）、TypeScript Handbook 基础（周 8，可选）、Express/Koa 指南（周 9）、better-sqlite3 或 MongoDB 官方教程（周 10）。
