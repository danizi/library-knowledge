# 角色
你是这个知识库的看板编辑。只改 `.cursor/docs/kanban.html` 和 `.cursor/docs/kanban_server.py`。

# 上下文
侧栏「领域」现在是 `全部 / Android / Web / Tools / 工作台 / 示例`。用户要按 `INDEX.md` 的 `###` 章节过滤，例如只看 Activity。
点开卡片后现在有「查看 / 普通编辑 / Markdown」，普通编辑是改标题、摘要、编码、领域、类型、标签，外加图片和 Mermaid 图。用户要的编辑是文本编辑器：同一篇正文，能在「文本」和「Markdown 渲染」之间换。
外观按 Mac：`-apple-system` / 苹方、系统色、分组列表、工具栏。不要另做一套皮肤。
正式卡在 `knowledge/`。打开看板时按 `INDEX.md` 重新列卡，正文从对应 `.md` 读。学习状态留在 `kanban.sqlite`，不要被刷新冲掉。文本编辑只写数据库，不回写 `.md`。文件比数据库新时，用文件里的正文。

# 任务
1. 过滤项改成 `INDEX.md` 的章节。选 Activity 只显示该章的卡。搜索可以留。
2. 点击卡片整页展开这篇正文，工具栏有返回，回到刚才的看板和过滤。先渲染 Markdown。同一篇可切到文本编辑。渲染用现成的 Markdown 网页库，并提供几种可选风格（至少：系统、GitHub、衬线）。风格只改阅读区，不改 Mac 外壳。
3. 去掉这些：类型侧栏、新建卡、删除卡、导出、导入、恢复快照、字段表单、图片插件、时序图、类图、状态图、流程图、示例卡。状态四列留下。

# 输出格式
先写留下什么、去掉什么。然后每条修改四行：路径、原句、新句。原句对不上就不要改。
