# React 基本语法

**问：**
`import { useState } from 'react'` 是什么意思？它在组件里解决啥问题？

**答：**
从 React 库里导入名为 `useState` 的 Hook。  
`useState` 让函数组件能保存会随时间变化的值；值一变，组件按新值重新渲染。  
花括号是 ES Module 的**具名导入**写法。

一句话：这行 = 请来 `useState`，让函数组件也能有「会变的状态」。

**例 / 类比：**
```jsx
import { useState } from 'react'
function Counter() {
  const [n, setN] = useState(0)
  return <button onClick={() => setN(n + 1)}>{n}</button>
}
```
- 类比：从工具墙（react 包）取下一把「状态钳」。

**易错：**
- Hook 只能写在函数组件顶层，不能写在普通 if/循环里。
- 和 `import React from 'react'` 默认导入不是一回事。
