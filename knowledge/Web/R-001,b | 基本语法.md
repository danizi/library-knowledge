# React 基本语法

**问：** `import { useState } from 'react'` 在函数组件里解决什么问题？

> **一句话：** 这行从 React 导入 `useState`。函数组件用它保存会变化的值。

**例：** 按钮每点击一次，就把 `n` 加 1，并显示新的 `n`。

```jsx
import { useState } from 'react'

function Counter() {
  const [n, setN] = useState(0)
  return <button onClick={() => setN(n + 1)}>{n}</button>
}
```

<details>
<summary>答</summary>

这行从 React 库导入名为 `useState` 的 Hook。
花括号是 ES Module 的具名导入。
`useState` 让函数组件保存一个会随时间变化的值。
这个值一变，组件按新值重新渲染。

</details>

<details>
<summary>易错</summary>

- Hook 只能写在函数组件的顶层。不要把 Hook 写在普通 `if` 里。不要把 Hook 写在循环里。
- 这行和 `import React from 'react'` 不是同一种导入。后一种是默认导入。

</details>
