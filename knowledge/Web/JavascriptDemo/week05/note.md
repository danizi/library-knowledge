# 第 5 周笔记（收尾与自测）

## 收获与要点
- 表单校验：先用 `reportValidity` 兜底，再用自定义规则（trim、长度、重复）集中展示错误。
- 错误聚合：所有业务错误写到 `#form-error`，不再用 alert；一次提交只返回一次提示。
- localStorage 封装：`loadTodos` 带 try/catch，坏 JSON 自动回退空数组并写回；`saveTodos` 统一持久化。
- 渲染与统计：根据 `todos` 生成列表，切换完成/删除后重渲染并更新 `Total/Active/Complete`。

## 踩坑记录
- 未 `preventDefault` 导致表单刷新；按钮默认 `type="submit"` 需显式声明。
- 字符串乱码：确保提示文案用可读中文并闭合引号。
- JSON.parse 报错：本地存储被手动改坏时要兜底写回 `[]`。
- 重复校验遗漏 trim/大小写统一，导致同名项重复。

## 自测结果（请边测边勾选/备注）
- [ ] 空/过短/重复：只显示错误提示且不提交。
- [ ] 正常添加：列表展示，计数变化，输入清空并聚焦，刷新后仍存在。
- [ ] 切换完成：样式与计数同步，刷新后状态保持。
- [ ] 删除：项消失，计数更新，刷新后仍消失。
- [ ] 持久化健壮性：localStorage 填入 `bad` 后刷新，页面不报错并重置为空且计数归零。
> 备注：如有未通过，请记录原因与改进想法。
