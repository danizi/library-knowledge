# React 项目使用及说明

**问：** Vite 建好的 React 项目里，入口文件和根组件各是哪一个？

> **一句话：** `src/main.jsx` 是入口。`src/App.jsx` 是根组件。插件用来写得更快、格式更一致。

**例：** `src/main.jsx` 渲染 `App`。界面从 `src/App.jsx` 长出来。

<details>
<summary>答</summary>

`src/main.jsx` 负责挂载。
`src/App.jsx` 是根组件。
`index.html` 提供挂载点。
`package.json` 记录脚本和依赖。
`vite.config.js` 是构建配置。
常用插件有 ES7+ snippets、ESLint、Prettier、Auto Rename Tag 和 Path Intellisense。
调试可以使用浏览器调试扩展。
其余目录按需要再深入。

</details>

<details>
<summary>类比</summary>

`main` 是大门。`App` 是客厅。客人先进客厅。

</details>

<details>
<summary>易错</summary>

- 改错了入口文件时，不要只盯着 `App` 找原因。
- 依赖安装在项目里。不要只安装到全局。

</details>
