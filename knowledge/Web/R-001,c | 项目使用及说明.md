# React 项目使用及说明

**问：**
Vite 建好的 React 项目，目录各自干啥？VS Code 里常装哪些插件？

**答：**
关键：`src/main.jsx` 入口挂载，`src/App.jsx` 根组件，`index.html` 挂载点，`package.json` 脚本与依赖，`vite.config.js` 构建配置。  
插件常用：ES7+ snippets、ESLint、Prettier、Auto Rename Tag、Path Intellisense；调试可用浏览器调试相关扩展。

一句话：认入口与 App，其余按需深入；插件负责写得快、写得干净。

**例 / 类比：**
```text
src/main.jsx → 渲染 <App />
src/App.jsx  → 你的界面从这里长出来
```
- 类比：main 是大门，App 是客厅——客人先到客厅。

**易错：**
- 改错入口文件却盯着 App 找原因。
- 依赖装全局而不是项目里。
