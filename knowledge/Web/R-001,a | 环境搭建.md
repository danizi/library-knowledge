# React 环境搭建

**问：** 从零跑起一个 React 页面，最少要准备什么？

> **一句话：** 安装能运行 `npm` 的 Node.js。再用 Vite 把 React 跑到能热更新。

**例：** 创建出 `react-hello`。执行 `npm run dev` 后打开本地页面。修改 App 里的文字后，浏览器跟着变。命令写在过程卡里。

<details>
<summary>答</summary>

要有能运行 `npm` 的 Node.js LTS。
要有一个编辑器。这里使用 VS Code。
脚手架使用 Vite 加 React。
Vite 的开发服务器启动快。
官方模板足够做一个 Hello World。
新项目不再把 CRA 当作默认选择。
修改 `src/App.jsx` 之后，页面自己更新。
这时环境算接通了。

</details>

<details>
<summary>类比</summary>

先装灶台和燃气。然后再谈菜谱。

</details>

<details>
<summary>易错</summary>

- 不要把 `npm` 打成 `nmp`。
- 不要在还没有进入新建的项目目录时执行 `npm install`。
- 不要把环境步骤和语法写成一篇长文。

</details>
