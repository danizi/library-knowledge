# React 环境搭建

> 状态：步骤已拆到过程卡 · **本卡仍待审卡**

**问：**
从零跑一个 React 页面，最小要准备啥？为啥新项目用 Vite，而不是 CRA？

**答：**
要有能跑 `npm` 的 Node.js LTS，以及一个编辑器（这里用 VS Code）。  
脚手架用 **Vite + React**：开发服务器启动快，官方模板够一个 Hello World。CRA 已不作为新项目的默认选择。  
改 `src/App.jsx` 后页面自己更新，环境就算通了。

一句话：Node 能跑 npm，再用 Vite 把 React 跑到能热更新。

**例 / 类比：**
- 例子：创建出 `react-hello`，`npm run dev` 打开本地页，改 App 里的字，浏览器跟着变。命令见过程卡。
- 类比：先装灶台和液化气，再谈炒菜谱。

**易错：**
- 把 `npm` 打成 `nmp`。
- 没进入新建的项目目录就 `npm install`。
- 环境步骤和语法揉成一篇长文。
