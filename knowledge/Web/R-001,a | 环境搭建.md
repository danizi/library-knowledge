# React 环境搭建

**问：**
用 VS Code 从零跑一个 React Hello World，最小要准备啥？推荐哪条脚手架？

**答：**
准备：VS Code、Node.js LTS（`node -v` / `npm -v` 有输出）、常用 React 插件（snippets / ESLint / Prettier）。  
脚手架优先 **Vite + React**（快）；CRA 已偏旧。创建后改 `src/App.jsx`，`npm run dev` 能看见页面即成功。

一句话：Node + Vite 创建 React 项目，改 App 能热更新就算环境 OK。

**例 / 类比：**
```bash
npm create vite@latest react-hello -- --template react
cd react-hello && npm install && npm run dev
```
（若网络问题可换镜像；命令以官网当前为准。）
- 类比：先装灶台和液化气，再谈炒菜谱。

**易错：**
- 把 `npx`/`npm create` 打成 `nmp`。
- 没进对目录就 `npm install`。
