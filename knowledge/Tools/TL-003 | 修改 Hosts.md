# 修改 Hosts

> 状态：步骤已拆到过程卡 · **本卡仍待审卡**

**问：**
hosts 文件是干啥的？改完为啥经常「不生效」？

**答：**
hosts 把「域名 → IP」写死在这一台电脑上，查找时优先于 DNS，用来把测试域名绑到本机或内网。  
它是系统文件，普通权限常常存不进去。即便写进去了，系统和浏览器还可能记着旧解析；缓存不刷新，打开的仍是旧地址。

一句话：hosts 是本机的域名小抄；没写进去，或缓存没清，都等于没改。

**例 / 类比：**
```text
127.0.0.1   www.my-dev.local
```
- 类比：给朋友起外号并写在自己的通讯录里——只有这台机器认；通讯录没保存成功，或还翻着旧页，都找不到人。

**易错：**
- 普通权限打开，「看起来改了」其实没存到系统那份文件。
- 文件改了，却不刷新 DNS、不重开浏览器。
