# Python

**问：** 有 Java 或 Kotlin 基础时，一天入门 Python 先抓住什么？

> **一句话：** 先学和 JVM 语言不同的写法。再写能跑的小脚本。用到框架再查文档。

**例：** 用 `python3 hello.py` 跑通打印。再用 `list` 与 `dict` 改一段熟悉的业务逻辑。

<details>
<summary>答</summary>

Python 用缩进划分代码块。
运行命令优先写 `python3`。
类型在运行时决定。
集合常用 `list`、`dict`、`set`、`tuple`。
资源用 `with` 管理。
一个 `.py` 文件就是一个模块。
应用向的模型调用走 AI 章，不在本章展开。

</details>

<details>
<summary>类比</summary>

Java/Kotlin 是带说明书的工具箱。Python 先给你一把能拧螺丝的扳手，说明书按需再翻。

</details>

<details>
<summary>易错</summary>

- 不要从零把「什么是循环」再学一遍。
- 不要把 AI 应用主线当成语法入门主线。

</details>
