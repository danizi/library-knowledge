# 语法差异

**问：** 从 Kotlin 写到 Python，最先要改掉哪些字面量与运算符？

> **一句话：** 布尔写成 `True` 和 `False`。空值写成 `None`。逻辑用 `and`、`or`、`not`。

**例：** `ok = name is not None and len(name) > 0`。字符串用 `f"hi {name}"`。

<details>
<summary>答</summary>

Python 不用 `true`、`false`、`null`。
条件分支是 `if`、`elif`、`else`。
三元写法是 `a if cond else b`。
相等用 `==` 比内容。
`is` 比是否同一对象。
函数用 `def` 定义。

</details>

<details>
<summary>易错</summary>

- 不要写 `if x == None`。写 `if x is None`。
- 不要假设终端里一定有 `python` 命令。

</details>
