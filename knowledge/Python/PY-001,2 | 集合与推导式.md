# 集合与推导式

**问：** Python 里 list、dict 和列表推导式各解决什么问题？

> **一句话：** `list` 保序存放多项。`dict` 用键取值。推导式在一次表达式里完成映射和过滤。

**例：** `counts = {}` 后对词做 `counts[w] = counts.get(w, 0) + 1`。或 `[w.upper() for w in words if w]`。

<details>
<summary>答</summary>

`list` 对应可变有序列表。
`dict` 对应键值映射。
`set` 去重。
`tuple` 不可变。
切片用 `a[start:stop]`。
`enumerate` 同时给出下标与元素。
推导式对标 Kotlin 的 `map` 与 `filter` 短写。

</details>

<details>
<summary>易错</summary>

- 不要把空 `list` 当成「对象不存在」。空容器在 `if` 里是假。
- 不要在看不清引用时只靠猜。打开 Python Tutor。
