# 标准库入门

**问：** 一天入门时，标准库先会哪两个？

> **一句话：** 路径用 `pathlib.Path`。结构化数据用 `json`。

**例：** `Path("notes.txt").read_text(encoding="utf-8")` 读文本。`json.dump(data, f, ensure_ascii=False)` 写出。

<details>
<summary>答</summary>

`Path` 处理路径拼接与读写。
`json` 在 Python 对象和 JSON 文本之间转换。
`sys.argv` 读命令行参数。
类型标注可用 `list[str]` 与 `X | None`（3.10+）。
HTTP 客户端需要时再装 `requests`。

</details>

<details>
<summary>易错</summary>

- 不要在验收脚本里先上 Web 框架。
- 不要忽略文本编码。读写写明 `utf-8`。

</details>
