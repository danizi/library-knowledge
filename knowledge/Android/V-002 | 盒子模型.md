# 盒子模型

**问：** 一个 View 在屏幕上占的地方，从里到外是哪几层？

**答：**  
从里到外四层：**内容（content）→ 内边距（padding）→ 边框（border）→ 外边距（margin）**。  
测量到的宽高通常包含内容+padding（具体 API 以文档为准）；margin 是和其他兄弟控件之间的空隙，不属于自己「画」的区域。

**例：** 按钮文字是内容；文字到边框的空隙是 padding；按钮外和其他控件隔开的是 margin。

**易错：**
- 改「变大一点」时先分清要加 padding 还是 margin，别乱拧。
- 和 CSS 盒子模型直觉接近，但 Android 属性名/测量细节不完全一样。
