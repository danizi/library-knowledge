# 盒子模型

**问：** 一个 View 在屏幕上占的地方，从里到外是哪几层？

> **一句话：** 最里面是内容。然后是 padding。然后是 border。最外面是 margin。

**例：** 按钮文字是内容。文字到按钮边缘的空隙是 padding。这个按钮和其他控件之间的空隙是 margin。

<details>
<summary>答</summary>

从里到外有四层。
最里面是内容。
然后是 padding。padding 是内容和边框之间的空隙。
然后是 border。border 是边框。
最外面是 margin。margin 是这个 View 和其他 View 之间的空隙。
测量到的宽高通常包含内容和 padding。
margin 不属于这个 View 自己绘制的区域。

</details>

<details>
<summary>类比</summary>

画是内容。画和框之间的空隙是 padding。框条是 border。框和墙之间是 margin。

</details>

<details>
<summary>易错</summary>

- 想让区域变大时，先分清是增加 padding，还是增加 margin。
- 这四层和 CSS 接近。Android 的测量细节和 CSS 不完全相同。

</details>
