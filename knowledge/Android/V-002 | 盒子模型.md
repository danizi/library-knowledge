# 盒子模型

**问：**
一个 View 在屏幕上占的地方，从里到外是哪几层？

**答：**
从里到外四层：**内容 → 内边距（padding）→ 边框（border）→ 外边距（margin）**。  
测量到的宽高通常包含内容+padding；margin 是和其他兄弟之间的空隙，不属于自己「画」的区域。

一句话：内容在最里，padding 撑内空，border 描边，margin 隔开别人。

**例 / 类比：**
- 例子：按钮文字是内容；文字到边的空隙是 padding；按钮外和其他控件隔开的是 margin。
- 类比：像相框——画是内容，画与框的空隙是 padding，框条是 border，框与墙之间是 margin。

**易错：**
- 想「变大一点」时先分清加 padding 还是 margin。
- 和 CSS 直觉接近，但 Android 测量细节不完全一样。
