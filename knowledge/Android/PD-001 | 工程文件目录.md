# 工程文件目录

**问：**
新建一个 Android 工程，日常开发到底主要盯哪些目录？

**答：**
日常几乎都在 `app/src/main/`：`java/`（或 kotlin 源码）、`res/`（资源）、`AndroidManifest.xml`。  
根上的 `build.gradle` / `settings.gradle` / `gradle/` 管构建；`.gradle`、`build/` 是生成物可忽略。  
切换到 Project 视图看树，细节因 AS 版本略有差异，抓主干即可。

一句话：代码与资源在 `app/src/main`，其余大多是构建与缓存。

**例 / 类比：**
- 例子：改界面 → `res/layout`；改逻辑 → `java/...`；改组件声明 → Manifest。
- 类比：main 是营业厅，build 是仓库垃圾间——别把时间耗在垃圾间。

**易错：**
- 死记整棵树；用到再查。
- 把 `local.properties`（本机 SDK 路径）提交进 Git。
