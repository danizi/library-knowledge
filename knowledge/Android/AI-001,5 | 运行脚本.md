# 运行脚本

**问：** `python3 hello.py` 在做什么？

> **一句话：** Python 读取 `hello.py` 并执行里面的语句。`print` 把文字写到终端。

**例：** `ai-d0-hello` 里这一句是 `print("你好，这是第一行")`。运行后终端多出这一行。

<details>
<summary>答</summary>

`.py` 文件里存的是语句。
`python3 hello.py` 让 Python 打开这个文件。
Python 从上到下执行语句。
`print` 把括号里的文字写到终端。
终端里的这一行是程序的输出。
它不是文件名。

</details>

<details>
<summary>易错</summary>

- 不要在别的目录里运行。Python 会找不到 `hello.py`。

</details>
