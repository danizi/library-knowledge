# D10 · 头像短视频

这是第 2 个 Demo。

1. 把本人照片保存为本目录的 `avatar.jpg`。不要用影视截图。
2. `script.txt` 可以改成你的三句话。不要写片名、角色名、影视对白。
3. 运行：

```bash
cd /Users/a1234/xiaomin/library-knowledge/knowledge/Android/demos/ai/ai-d10-avatar
export DASHSCOPE_API_KEY="你的百炼密钥"
export WORKSPACE_ID="你的业务空间ID"
python3 avatar.py
```

做完标准：本目录的 `avatar.mp4` 能播放。程序不发抖音。

输入：https://help.aliyun.com/zh/model-studio/image-to-video-general-api-reference
怎么做：提交本人头像和原创口播稿。
