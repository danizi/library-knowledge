# 开发踩坑记录

**问：**
这几类常见坑分别是啥原因、怎么解？（配置变更刷新 / 图片缩放 / 多模块字符串 R / findViewById 同 id）

**答：**
1. **隐藏 Fragment 要刷新**：`hide/show` 时别死靠 `onResume`，常在 `onHiddenChanged` 里更新。  
2. **图片被扯歪**：固定宽高时用 `fitCenter`（或 Glide `FitCenter()`）；自适应另议。  
3. **多模块 `R.string` 找不到**：子模块 `namespace` 不能和依赖方撞车，各模块唯一。  
4. **同布局 include 两份**：`findViewById` 同 id 会拿到**第一个**；给每个 `<include>` 自己的 id，再在子树里找。

一句话：坑多半是「生命周期假设错 / 资源命名空间撞车 / 查找作用域太大」。

**例 / 类比：**
- 例子：A/B 两个 include 同布局 → `layoutA.findViewById` / `layoutB.findViewById`。
- 类比：两间房都有「开关」——先走进对的房间再找开关。

**易错：**
- 模块 namespace 复制粘贴忘改。
- 以为刷新一定走 `onResume`。
