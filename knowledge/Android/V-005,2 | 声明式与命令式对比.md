# 声明式与命令式对比

**问：**
写 UI 时「命令式」和「声明式」差在哪？为啥 Compose 叫声明式？

**答：**
- **命令式**：一步步下令——找到控件、改文字、设可见性……UI 是「被改出来的」。  
- **声明式**：描述「当前状态下 UI 应该是什么」；状态变了，框架对齐到新描述。

一句话：命令式管「怎么改」，声明式管「是什么」。

**例 / 类比：**
- 计数器：命令式改 `textView.text`；声明式只改 `count`，UI 写 `Text("$count")`。
- 类比：命令式像亲手摆棋子；声明式像报棋谱，棋盘按谱自动摆。

**易错：**
- 在 Compose 里继续握控件引用会对不上重组。
- 声明式也能写逻辑——逻辑应推动**状态**。
