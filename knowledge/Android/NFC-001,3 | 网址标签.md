# 网址标签

**问：** 标签保存的是 http 或 https 地址时，为什么 `ACTION_NDEF_DISCOVERED` 过滤器收不到这个标签？

> **一句话：** 从 Android 16 起，http 标签和 https 标签使用 `ACTION_VIEW`。

**例：** `nfc-d3-view` 收到 `ACTION_VIEW` 时显示网址。收到其他 NFC Action 时显示该 Action。没有标签时显示「还没贴到标签」。

<details>
<summary>答</summary>

从 Android 16 起，http 标签和 https 标签使用 `ACTION_VIEW`。
这些标签不使用 `ACTION_NDEF_DISCOVERED`。
从 Android 17 起，系统先显示「打开链接」通知。
用户点击该通知。系统然后发送 `ACTION_VIEW`。
要接收这些标签，为 `ACTION_VIEW` 写过滤器。

</details>

<details>
<summary>类比</summary>

信封上印了网址。邮局把这封信送到浏览器，不送到 NDEF 信箱。

</details>

<details>
<summary>易错</summary>

- 不要认为所有 NDEF 标签都使用 `ACTION_NDEF_DISCOVERED`。http 标签和 https 标签从 Android 16 起不是这样。
- 不要忽略 Android 17 的用户确认。用户必须先点击通知。

</details>
