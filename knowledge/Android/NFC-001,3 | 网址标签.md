# 网址标签

**问：**
标签里存的是 http 或 https，为什么 `ACTION_NDEF_DISCOVERED` 的过滤器收不到？

**答：**
从 Android 16 起，这种网址标签改发 `ACTION_VIEW`，不再发 `ACTION_NDEF_DISCOVERED`。从 Android 17 起，系统先弹出「打开链接」通知，用户点了才发出 `ACTION_VIEW`。要接这种标签，按打开链接的方式过滤，而不是只守着 NDEF。

一句话：Android 16 起，网址标签走 ACTION_VIEW，不再走 NDEF_DISCOVERED。

**例 / 类比：**
- 例子：nfc-d3-view 如果进来的是 `ACTION_VIEW`，只显示网址；否则显示 Action，没贴到就停在提示句。
- 类比：信的封面印了网址，邮局改投到浏览器窗口，不再投进 NDEF 信箱。

**易错：**
- 用 Android 16 以前的经验，认为所有 NDEF 都还走 `ACTION_NDEF_DISCOVERED`。
- 忽略 Android 17 多了一次用户确认。
