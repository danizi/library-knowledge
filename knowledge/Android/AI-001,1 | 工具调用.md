# 工具调用

**问：** 模型要读笔记时，谁去读文件？

> **一句话：** 模型只返回工具名和参数。Python 按文件名打开文件，再把正文送回模型。

**例：** `ai-d4-tool` 的日志先出现 `read_note`。然后出现 `cold.md` 的正文。然后才有最终回答。

<details>
<summary>答</summary>

工具定义写明三件事。名字是 `read_note`。说明告诉模型何时使用它。参数说明文件名是字符串。
程序把这份定义和用户问题一起发给模型。
模型决定调用工具时，回复里带有 `tool_calls`。
`tool_calls` 里有工具名和参数。参数是一段 JSON。
Python 解析出文件名。Python 读取 `docs` 里的那个文件。
Python 把正文作为 `role` 为 `tool` 的消息送回。
模型看到正文后，才写出最终回答。
模型没有打开磁盘。

</details>

<details>
<summary>易错</summary>

- 不要说模型自己打开了磁盘上的文件。

</details>
