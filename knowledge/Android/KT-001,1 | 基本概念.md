# 并发基本概念对照

**问：**
同步/异步、阻塞/非阻塞、并发/并行、进程/线程/协程——这几组词到底在区分什么？

**答：**
- **同步 / 异步**：结果怎么拿——卡住等，还是稍后再通知你。  
- **阻塞 / 非阻塞**：等的时候当前线程能不能干别的。  
- **并发 / 并行**：多任务是交替推进，还是同一时刻一起跑。  
- **进程 / 线程 / 协程**：资源与调度的粒度——进程最重，线程轻些，协程由应用调度、更轻。

一句话：四组词分别谈「怎么拿结果、线程闲不闲、多任务怎么叠、调度粒度多细」。

**例 / 类比：**
- 例子：点外卖——下单后继续工作是异步；死盯骑手位置是同步感。  
- 类比：进程=房子，线程=房里的人，协程=同一个人快速切换干多件家务。

**易错：**
- 把异步当成「一定多线程」。
- 把并发当成并行（单核也能并发）。
