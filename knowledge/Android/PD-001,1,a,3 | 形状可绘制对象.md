# 形状可绘制对象

**问：** `shape` 适合画哪一类背景？

> **一句话：** `shape` 用 XML 或代码画出形状背景。它常用来代替简单的切图。

**例：** 下面这个矩形有 12dp 圆角，并且使用线性渐变。

```xml
<shape xmlns:android="http://schemas.android.com/apk/res/android"
    android:shape="rectangle">
    <corners android:radius="12dp" />
    <gradient
        android:type="linear"
        android:startColor="#2196F3"
        android:endColor="#F44336"
        android:angle="90" />
</shape>
```

<details>
<summary>答</summary>

`shape` 可以画矩形和椭圆等形状背景。
`shape` 可以画描边、圆角和渐变。
使用 `shape` 可以少切图。
渐变的常见类型有线性 `linear`、径向 `radial` 和扫描 `sweep`。
日常按钮背景使用线性渐变加圆角即可。
代码里的对应类是 `GradientDrawable`。

</details>

<details>
<summary>类比</summary>

用笔当场画出按钮底色。不要每次都导出一张 PNG。

</details>

<details>
<summary>易错</summary>

- `angle` 只对线性渐变有意义。`angle` 必须是 45 的倍数。
- 代码里的 `cornerRadius` 单位是 px。不要把它和 dp 当成同一单位。

</details>
