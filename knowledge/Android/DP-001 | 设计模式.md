# 设计模式

**问：**
在 Android/日常开发里，设计模式是啥？这张卡打算怎么用？

**答：**
设计模式是「反复出现的问题」的可复用解法名字（创建、结构、行为三大类）。  
本卡先当入口：遇到「又在重复造轮子」时，回来补具体模式的费曼子卡（单例、观察者、适配器等）。

一句话：模式 = 给常见问题起名的标准解法，不是炫技清单。

**例 / 类比：**
- 例子：RecyclerView.Adapter 像「适配器」——把数据形状接到列表 UI。
- 类比：菜谱名——「红烧」不是食材，是做法。

**易错：**
- 为用模式而用模式，代码更绕。
- 和架构分层（AAP-001）搅成一锅。
