# 蓝牙

**问：** 扫描或连接之前，应用必须确认蓝牙硬件的哪两件事？

> **一句话：** 先确认有蓝牙适配器。再请用户打开蓝牙功能。

**例：** 模拟器没有蓝牙适配器时，`getAdapter()` 返回 null。真机的蓝牙功能关闭时，适配器存在，`isEnabled()` 返回 false。

<details>
<summary>答</summary>

调用 `BluetoothManager.getAdapter()`。
返回值是 null。这台设备没有蓝牙适配器。
返回值不是 null。这台设备有蓝牙适配器。
调用适配器的 `isEnabled()`。
返回值是 false。蓝牙功能未打开。
返回值是 false 时，发送 `ACTION_REQUEST_ENABLE`。
用户同意。结果是 `RESULT_OK`。
用户拒绝或打开失败。结果是 `RESULT_CANCELED`。
蓝牙功能打开之后，应用可以使用经典蓝牙。
蓝牙功能打开之后，应用可以使用 BLE。

</details>

<details>
<summary>类比</summary>

先确认有网线口。再请主人打开路由器电源。

</details>

<details>
<summary>易错</summary>

- 不要把 null 和 false 当成同一种状态。
- null 表示没有蓝牙适配器。
- false 表示有蓝牙适配器，但蓝牙功能未打开。

</details>
