# 蓝牙

**问：**
应用在扫描或连接之前，要先确认蓝牙硬件的哪两件事？

**答：**
用 `BluetoothManager.getAdapter()` 拿这台机器自己的蓝牙适配器。返回 null，就是没有蓝牙，相关功能关掉。不是 null 时再看 `isEnabled()`。false 表示无线电关着，发 `ACTION_REQUEST_ENABLE` 让系统问用户开不开。用户同意，结果是 `RESULT_OK`；拒绝或失败，是 `RESULT_CANCELED`。打开之后，经典蓝牙和 BLE 才都能接着用。

一句话：先确认有适配器，再请用户把无线电打开。

**例 / 类比：**
- 例子：模拟器没配蓝牙时 `getAdapter()` 为 null；真机关着蓝牙时适配器还在，但 `isEnabled()` 为 false。
- 类比：先看房子有没有网线口，再问主人要不要把路由器电源打开。

**易错：**
- 把 null 和「关着」当成同一种状态。null 是没有硬件，false 是有硬件但没开。
