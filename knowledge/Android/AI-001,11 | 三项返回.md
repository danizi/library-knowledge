# 三项返回

**问：** `/ask` 成功时，响应里必须有哪三项？

> **一句话：** 响应里有 `answer`、`filename` 和 `elapsed_ms`。

**例：** `ai-d8-ask` 问冷启动。`filename` 是 `cold.md`。`elapsed_ms` 是一个整数。

<details>
<summary>答</summary>

`FastAPI` 在本机提供一个 HTTP 服务。
浏览器打开 `http://127.0.0.1:8000/docs`。这一页列出服务接受的请求。
`POST /ask` 接收一个 JSON 对象。对象里的 `text` 是问题。
服务先做检索。检索失败时，`answer` 是「不知道」，另外两项为空或 0。
检索成功时，服务把段落交给模型。
`answer` 是模型的回复。`filename` 是用到的笔记。`elapsed_ms` 是这次模型调用的毫秒。

</details>

<details>
<summary>易错</summary>

- 不要只看回答文字。文件名和毫秒也要在响应里。

</details>
