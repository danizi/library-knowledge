# View 的定义

<details open>
  <summary>卡片内容</summary>

  - **核心问题**
    Android 中用户可见界面由什么构成？View 与 ViewGroup 的关系是什么？

  - **标准答案**
    用户可见并可交互的界面都由 `View` 与 `ViewGroup` 派生而来。`View` 负责绘制与交互；`ViewGroup` 本身通常不可见，是存放子 View 的容器。
